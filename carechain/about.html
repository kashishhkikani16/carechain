About CareChain

CareChain is a resource traceability system designed to make the process of requesting and tracking essential resources simple and transparent.

Our Objective

The main objective of CareChain is to help people request essential resources and track their requests from the initial request until delivery.

Resources Available

  • Medicine
  • Food
  • Clothes
  • Other Resources

Request Tracking

Every request receives a unique Request ID. Users can enter this ID on the Track page to check the current status of their request.

Status Flow

Request Received → Processing → Dispatched → In Transit → Delivered
